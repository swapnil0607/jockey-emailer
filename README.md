# Jockey — Living in Leggings Emailer

An editorial, responsive HTML/CSS emailer layout for Jockey's "Living in Leggings" collection campaign.

## Design Highlights
- **Editorial Layout**: 650px centered container with modern flexbox and grid layouts.
- **Hero Section**: Botanical bokeh background with high-contrast text overlay and bold CTA.
- **Editorial Category Overlays**: Bold white category/product labels placed directly at the bottom-left of lifestyle images with right chevrons (`>`).
- **Product Mappings**:
  - `01 — Performance` (MW12, MW68) — 2-column lifestyle grid
  - `02 — Yoga` (JW55) — 3-column lifestyle grid
  - `03 — Work & Weekend` (IW05) — 3-column lifestyle grid
  - `04 — Casual Moments` (AW87) — 3-column lifestyle grid
- **Interactive Footer**: Official Jockey brand logo in the header and individual social media hover icons (Instagram, X, Facebook, YouTube) in the footer.
- **Typography**:
  - Header: Gotham Condensed Bold
  - Body & Descriptions: Gotham Book
  - Titles & CTAs: Gotham Black

## How to Preview
Open `index.html` in any modern web browser (Google Chrome recommended for DevTools responsive screenshotting).
